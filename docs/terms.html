この利用規約(以下「本規約」)は、「余白」(以下「本アプリ」)の利用条件を定めるものです。本アプリをダウンロードまたは利用した時点で、本規約に同意したものとみなします。

1. 適用

本規約は、本アプリの利用に関する、ユーザーと開発者との間のすべての関係に適用されます。あわせて、Apple Inc. の「Apple Media Services 利用条件」および「App Store 利用規約」(標準の使用許諾契約)が適用されます。本規約と食い違う場合は、Apple の規約が優先されます。

2. Pro について

  • Pro は、家計簿を複数使う機能、外観「夜」、月次の一枚の書き出しと共有を解放する有料の機能です。
  • 購入の方法は、月額プラン(自動更新サブスクリプション)と買い切りプランの2つです。価格は、アプリ内のプランの画面に表示されます。
  • 支払いは、購入の確認時に、ユーザーの Apple ID のアカウントに請求されます。

3. 月額プランの自動更新と解約

  • 月額プランは、現在の期間が終わる少なくとも24時間前までに解約しない限り、同じ期間・同じ料金で自動的に更新されます。
  • 更新の料金は、現在の期間が終わる24時間以内に、Apple ID のアカウントに請求されます。
  • 解約と更新の管理は、購入後に、iPhone の「設定」→ 自分の名前 →「サブスクリプション」から、いつでもできます。
  • 期間の途中で解約しても、すでに支払った料金の日割りの返金は行いません。期間の終わりまで、Pro を使えます。
  • 返金は、Apple の定める手続き(reportaproblem.apple.com)によります。開発者が直接、返金をすることはできません。

4. データの扱い

  • 本アプリのデータは、ユーザーの端末の中にだけ保存されます。開発者は、ユーザーのデータを預かっておらず、失われたデータを復元することはできません。
  • 端末の紛失・故障・アプリの削除に備えて、ユーザー自身の責任で、バックアップ機能を使ってください。
  • Pro の期間が終わっても、それまでに登録した家計簿・記録は、そのまま読めます。

5. 禁止事項

  • 法令または公序良俗に反する行為。

  • 開発者や第三者に迷惑をかける行為。

  • 本アプリの内容は、予告なく変更・停止することがあります。
